# quanttide-report-of-payment-engineering

量潮支付工程报告 — 记录量潮支付工程领域的决策报告与复盘报告。

## 概述

本仓库用于维护量潮支付工程领域的报告信息，当前主要维护两类决策报告：

- 产品决策：产品方向、功能范围、商业化等产品层面的决策记录
- 技术决策：技术选型、架构、协议、数据模型等技术层面的决策记录
